# Zdjęcia klimatu wyjazdu

Cztery obrazy wygenerowane narzędziem `image_gen` (tryb wbudowany) 19 października 2026.
Ilustrują klimat wyjazdu; nie przedstawiają konkretnej miejscowości ani kempingu.
W aplikacji są dostarczane lokalnie i działają bez zewnętrznego serwisu zdjęciowego.

Pliki: `coast.jpg` (morze), `lake.jpg` (jezioro), `mountain.jpg` (góry), `forest.jpg` (las).
Format docelowy: JPEG, 768 × 768 px, jakość 85. Kadrowanie obrazu w interfejsie: `cover`.
Oryginalne pliki PNG pozostają w katalogu generated_images narzędzia.
