# Tło Paszportu podróżnika

`cover.jpg` — autorska ilustracja wygenerowana wbudowanym narzędziem `image_gen` przy użyciu umiejętności `imagegen`: akwarelowe jezioro i góry, leśna ścieżka oraz dziennik podróży i mapa po prawej stronie. Styl dopasowany do kafli Start w RazemGo. Ilustracja nie zawiera tekstu ani elementów interfejsu.

Pełny użyty prompt i sposób generacji zapisano w `cover.prompt.json`. Wynik skompresowano do JPEG 1024 × 1024 px z jakością 88, zachowując kompozycję.

`cover-wash.svg` dodaje osobno jasny gradient od lewej oraz od dołu, aby nazwa ekipy, poziom, pasek postępu i punkty pozostały czytelne. Treść jest renderowana jako natywne elementy interfejsu.
